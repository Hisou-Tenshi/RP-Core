# 公开边界与初版审查记录

## 源码来源

框架根据已有 RP 系统的架构问题独立重新实现，没有批量复制旧 src/、个人提示词或 Git 历史。未导入真实聊天、知识库、关系卡、日记、下载附件、日志、评估产物、数据库、加密故障包或凭证。

角色专属内容仅在合成天子示例、文档与测试中。引擎不硬编码角色名、个人地理位置、GitHub 账户、厂商端点、模型名或 Telegram ID。AGPLv3 正文来自 GitHub 标准许可证接口；源码许可标识为 AGPL-3.0-only。

## 数据与信任边界

- 公开代码不等于公开数据。真实实例应在独立私密目录/repo；不把 root 下的 data/ 当默认值。
- run-instance 只输出处理计数；serve 的协议输出含回复，必须进入私密管道。
- 模型文本与回灌内容不具备新增工具权限；可调用工具由私密 snapshot 明确声明。
- 写入副作用在成功状态事务中提交；生成失败不会提前改写日记或发送消息。
- 公共进程边界不转发适配器 stderr、原始异常、模型输出或私密错误正文。
- 公开 workflow 不上传运行数据 artifact、Release、Actions cache 或 Step Summary；运行任务关闭 uv cache，并在检出前验证实例仓库确实为私密。
- 带私密 token 的 workflow 仅运行受信的默认分支代码；PR CI 使用合成数据，不读取实例 secrets。
- 锁定依赖、固定 Action 提交；适配器 argv 无 shell；外部 schema 引用禁止。

私密适配器与其模型进程是受信任代码，继承运行环境，不受本框架沙箱限制。保护公开分支、部署权限与依赖更新是部署者责任。跨仓库 token 应只访问必要实例仓库。

## 已知边界

自动审查是基础检查，不是完整渗透测试或零泄露保证。身份与密钥扫描不会识别所有自然语言隐私。模型可能产生不适当的文本；结构验证与内部标签拦截不等于完整内容审核。

传输实现面向 macOS/Linux，使用 POSIX 进程组与管道；暂不声明原生 Windows 支持。

SQLite + Git 参考模式适用于低并发单写者；不自动处理二进制 Git 冲突。平台没有幂等能力时，不能保证跨系统绝不重复发送。参考 outbox 仅导出文件，不代表已送达用户。

发布前执行 tests、lint、schema 导出一致性检查、公开文件扫描、wheel 构建与工作流配置检查。以后更改协议应保留兼容基线。
