# 兼容承诺

## 代码共享

模型、平台、存储和旧数据兼容实现都在公开仓。私密仓只维护角色数据和声明式 io.json。个人数据变化不用改公开代码；逻辑改进在公开仓集中维护。新增角色只登记公开实例表及凭证，不复制代码。独立 fork 同步上游一次即可供它自己的全部角色使用。

## 数据契约

数据 I/O 使用 schema_version=1，driver 与 files/session_map 指定数据格式和位置，不指定命令或任意模块。已有数据库可以由公开兼容驱动直接读写；不要求所有旧角色先转换成原生新库。

协议或格式发生破坏性变化时必须显式版本化，并由公开迁移/兼容代码处理，不能要求每个角色仓维护一套 Python 迁移程序。

## rp/1

rp/1 作为编排与驱动接口保留：不删除既有方法、必填字段或枚举，不改变其语义；新可选字段可添加，未知可选字段忽略；新方法先协商能力。破坏性变化使用新主版本。

0.1 的 run-instance --manifest 仍供高级 stdio 集成使用；0.2 默认 init-instance 生成纯数据，推荐入口为 run --config PUBLIC_CONFIG --data-root PRIVATE_DATA。现有 stdio 请求/响应 fixture 保持兼容。
