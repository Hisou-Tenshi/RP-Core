# read_config_file

## 何时用
- 要查自己项目里的代码、配置、日志结构
- 第一次不知道文件在哪：先不传 `path` 看目录树

## 参数
- `path`（可选）：项目根目录下的相对路径，如 `src/tenshi_config.py`
- 省略 `path`：返回目录树 + 文件用途短注

## 行为
- 只能读项目根内文件，禁止 `..` 越界
- 返回全文（过长时主流程可能截断）

## 限制
- **每轮最多 3 次**
- 一次只读一个文件
- 这是「破第四面墙」读仓库，别对用户炫耀路径

## 示例
先看树：
```json
{}
```

再读文件：
```json
{"path": "src/perception_layer.py"}
```
