# search_web

## 何时用
- 问现实世界的时效信息：新闻、价格、天气细节、上映日期、平台更新
- 预注入的【世界知识】明显跑偏、过时或缺关键事实
- **不要**用 site: 限定；让搜索引擎自己找

## 参数
- `query`（必填）：短关键词，可中英日混排

## 行为
- 优先 Tavily API，失败则 DuckDuckGo
- GitHub Actions 环境有并发/速率限制，别连刷

## 限制
- **每轮最多 2 次** `search_web`
- 若搜索特工已注入足够证据，优先用现有内容，别重复搜

## 与 fetch_url 配合
1. `search_web` 拿候选链接与摘要
2. 对 1–2 条最相关 URL 再 `fetch_url` 读正文（别贪多）

## 示例
```json
{"query": "东方 Project 19 发售日"}
```
